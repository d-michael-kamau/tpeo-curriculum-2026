# Node and Express API demo

Build a tweet API using Express and an in-memory array. Complete the numbered TODOs in `index.js` during the walkthrough.

You need Node.js, npm, and Postman or another HTTP client. From this folder, run:

```sh
npm ci
node index.js
```

The server runs at `http://localhost:3000`. Unfinished routes return a `501` TODO response. Stop with Ctrl+C and restart after editing. Tweets reset when the server restarts.

For POST and DELETE requests, choose **Body -> raw -> JSON** in Postman.
