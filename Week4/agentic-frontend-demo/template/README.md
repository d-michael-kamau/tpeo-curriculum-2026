# TPEO Website — Starter Template

React + Vite + Tailwind starter for the **Agentic Frontend Development** workshop.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). You should see a placeholder page.

## Before you code

1. Open this `template/` folder as your project in Cursor so its instructions and skills are available.
2. Read [`AGENTS.md`](./AGENTS.md).
3. Connect Figma MCP in Cursor, or use a design system shared by your instructor.
4. Follow [`../WORKSHOP.md`](../WORKSHOP.md) and paste the prompts from [`../PROMPTS.md`](../PROMPTS.md).

## What you'll build

Agents will generate:

- `docs/DESIGN_SYSTEM.md`
- `src/components/sections/Navbar.jsx`
- `src/components/sections/Hero.jsx`
- `src/components/sections/FeatureCards.jsx`
- Optional UI primitives in `src/components/ui/`

## Custom Skills

Located in `.cursor/skills/`:

- **tpeo-design-system** — Figma → design tokens + `DESIGN_SYSTEM.md`
- **tpeo-design-qa** — Audit implementation vs design system
